## 证据与归因边界

远端独立诊断 `output/getup_recovery_probe_20261115_r01/probe.json`，工具
`tools/getup/probe_recovery.py`：不做优化器 step，不更新归一化，不导出交叉组合权重，
原模型文件哈希不变。四组共用 100 个参考起点、seed=456、600 物理步，确定性动作：

| 策略权重 | 观测归一化 | 末尾稳定率 | 平均最长站稳 |
|---|---|---:|---:|
| 原站立权重 | 原统计 | 19% | 5.95s |
| r02 权重 | r02 统计 | 0% | 0.20s |
| r02 权重 | 原统计 | 0% | 0.00s |
| 原站立权重 | r02 统计 | 30% | 7.99s |

诊断在 env/agent 构造后重设随机种子，且固定走 600 步；正式评测在构造前设种子，
走到 TIME 结束。因此诊断原模型 19% 与正式基线 16% 不应混作同一批样本。
该对照表明此次退化主要随 Actor 权重更新出现；恢复旧 normalizer 不能救回它，
新统计对旧 Actor 反而有利。故本轮不冻结/重置归一化，也不使用拼接权重训练。

同一随机种子下，在 100 环境原 90/10 混合分布采集一个 32 步训练 rollout，
实际 87 个站姿、13 个参考初始化。源模型测量：

| 项目 | 扰动站姿 | 97%～100% 参考帧 |
|---|---:|---:|
| 初始头高 | 1.348m | 1.335m |
| 初始 root 速率 | 0.0237m/s | 0.2346m/s |
| 初始平均关节速率 | 0 | 0.424rad/s |
| 相对中立姿态平均关节偏差 | 0.00592rad | 0.2388rad |
| 前 32 步平均 task reward | 1.000 | 1.000 |
| 同窗口平均 SMP reward | 0.000341 | 0.05164 |
| 标准化优势均值 | +0.0173 | -0.1450 |
| 观测裁剪元素比例 | 0.041% | 17.29% |

“动作时间接近结尾”不等于“接近中立站姿”。参考状态带运动速度和不同关节姿态，
对原站姿 Actor 是较大分布变化。参考重置使用原 motion 历史/速度，站姿使用静止
历史加最新帧速度脉冲；现有真实 Newton 测试检查了这项差异的一致性，未发现
本轮新增的历史/物理重置错配。

task 高度奖励在这两类高头部状态都饱和；保持平衡的差异需要后续轨迹反映。
原源模型的 SMP 即时信号并未更偏爱站姿，不能归因为“先验直接惩罚参考动作”。
优势含 Critic bootstrap 和全 batch 标准化：负均值不是 PPO 算错的证据，亦不能
直接解释为“奖励鼓励摔倒”。r02 的参考 task/SMP 均值下降到 0.962/0.00799，
优势均值却为 +0.156；这再次说明不能拿优势符号替代恢复验收。

另有一个明确流程问题：BaseAgent 每次输出都会用同一模拟器评测，然后重置。
原 `iters_per_output=5`、32 步/更新、30Hz，迭代 0 后每段训练最多 5.33s，
始终达不到 20s 回合；日志 Train_Episodes 一直为 0 与此吻合。
PPO 仍有 bootstrap，并非完全没有长期信号，但它没有采到完整训练回合。

结论：Actor 退化有交叉干预证据；轨迹截短是已确认的流程缺陷；90% 稳定站姿
掩盖稀少的动态恢复样本是待验证的学习失衡假设。没有证据证明其中单项是唯一原因。

## 本轮最小调整与下一轮

- 近站立 agent 的输出/评测间隔从 5 改为 20 次更新，连续训练窗口为 21.33s。
  保留原框架第 0 次更新后的初始评测；之后会经历完整 20s 回合，最后不足一个
  间隔时仍按预算退出。新增预检查拒绝会截短所有训练回合的间隔配置。
- 第一段参考采样从 10% 改为 50%，站姿锚点保留 50%。参考 phase、真实速度、
  站姿扰动幅度、奖励、冻结 prior、Actor/Critic 学习率和数值保护均不变。
- 增加逐样本初始化标签与分组日志：样本数、加权 task/SMP、标准化优势及正优势
  比例。非站姿在本课程中就是参考组，在其他 Getup 配置也可能包含倒地增强组。
  分组绑定采样当时标签，不能用 rollout 结束时的 slot 标签回填。
- 修复 Logger 固定列宽不加分隔符的问题：长指标名/长数值原来会粘连，导致按
  空白切列错位。新日志列之间显式加空格；不重写旧日志。诊断 r02 的任务效果取自
  独立 evaluation JSON，不能用旧日志错位的列值推翻它。
- 默认仅第一段，4096×32×32=4,194,304 samples，不自动启动第二段。
  仍从原 frozen_smp 站立模型热启动，不复用退化后的 r02。晋级验收门槛保留。

这是改善学习条件的修复尝试，不是已证实学会恢复。完整效果必须在用户 push 后，
远端同预算对照评测才能判断。计划命令：
