# RTX A5000：2048与4096环境容量测试

## 决策

远端4096环境负载测试通过。后续新训练默认4096；资源不足或资源相关崩溃时回退2048。
历史实验配置不改。此结论是容量判断，不代表G1技能效果或尚未实现的LaFAN表示适配已经通过。

## 测试口径

- G1使用`output/g1_paper_targets_full_20261105_r01`保存的env/agent/engine配置及已完成模型。
  该链路仍是两段动作先验；不是作者LaFAN适配后G1链路。
- Humanoid使用`output/a5000_dodgeball_2048_full_r01`保存配置及模型，加载作者冻结LaFAN先验。
- 相同seed=123、rollout=32；保留实际PPO、SMP评分、GSI生成、测试与最终模型保存。
  51次更新覆盖GSI第0及50次更新。随机权重和Humanoid组覆盖初始GSI及8次训练更新。
- 加载既有策略仅复用模型权重及normalizer，优化器新建；不能称为完整断点恢复。
- `profile_runner.py`只在进程内为`SMPAgent._train_iter`添加CUDA同步、计时及有限性检查，
  未修改仓库生产源文件。迭代计时包含rollout及训练，稳定吞吐排除前3次及第50次GSI刷新，
  不含初始化、独立测试和文件保存开销；表中全程耗时包含这些开销。
- 显存采用约2秒间隔nvidia-smi全卡dedicated memory采样，涵盖Warp等非PyTorch分配；
  短时尖峰可能未采到。每组另记PyTorch allocated/reserved峰值。
- 温度≥90°C、系统可用内存<1 GiB、遥测连续失败3次或单组超过1800秒时只停止自建测试进程；本次均未触发。

51次更新足以检查当前链路启动、更新、GSI刷新及保存的短期容量，不能排除数十小时后泄漏，
也不能提前证明新增骨架适配代码的负载。正式运行仍需确认实际显存及启动状态，出现资源异常回退2048。
